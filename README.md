# cyberjangle101.github.io

The root of cyberjangle101.github.io: links to the Rootkit 99 pages, plus the Google Search Console
file that proves this domain belongs to the Rootkit 99 developer (needed for the Google sign-in consent screen).

`app-ads.txt` authorises Google AdMob (publisher pub-4910871308559309) to sell the ads in Rootkit 99.
Keep it at the site root: AdMob reads it from the developer website on the Play Store listing.
